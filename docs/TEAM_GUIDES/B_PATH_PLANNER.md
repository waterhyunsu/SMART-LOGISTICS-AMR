# B · 정지호 — A*와 Dijkstra 비교

**목표와 범위.** 동일한 지도·Costmap·출발/목표에서 전역 플래너를 비교해 선택 근거를 제공한다. B의 비교 설정과 실험 스크립트는 원격 `feat/b-path-planner`에서 작업 중이다. 해당 브랜치의 `experiments/path_planner/`에서 이어서 작업한다.

1. D와 지도·프레임·플래너 환경을 맞추고 고정된 출발/목표 쌍 및 실패 사례를 정의한다.
2. NavFn의 A*·Dijkstra 설정을 분리하고 같은 조건으로 ComputePathToPose 결과를 수집한다. 경로 길이(m), 계획 시간, 성공 여부와 설정 ID를 기록한다.
3. D에는 추천 설정과 재현 절차, C에는 비용표 계산에 쓸 플래너 ID·설정 버전, E에는 실험 레코드를 제공한다. 방문 순서 선정과 비용표 버전 발급은 C의 책임이다.

**완료·테스트.** 동일한 시작 Pose를 명시해 두 설정에서 같은 쌍을 재실행한다. 도달 불가 구간이 실패로 남고 설정·지도 버전별로 결과를 분리할 수 있어야 한다. 측정값은 SIM 또는 REAL로 표시한다. 실제 주행 거리는 별도 측정이다.

**협업.** 기존 `feat/b-path-planner`를 추적한다. 새 실험 브랜치는 현재 작업을 보존한 뒤 [브랜치 선택 절차](README.md)를 따른다. PR에 비교 명령, 설정 차이와 실측 표를 첨부한다. D의 배포 설정 수정은 D와 협의하고 이유를 적는다. 공통 ROS 타입은 A의 변경 승인이 필요하다.
